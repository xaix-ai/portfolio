# portfolio

Create a modern, playful, highly interactive, responsive personal portfolio website with a strong pink aesthetic.

The portfolio should feel creative, personal, polished, and slightly experimental rather than looking like a generic developer portfolio. The design should have a soft, dreamy, futuristic feel inspired by creative interactive websites. Use motion and animated elements throughout the website, but keep the overall interface clean and easy to navigate.

IMPORTANT:

This is a personal portfolio for an undergraduate IT student/developer who is still growing and building skills. The portfolio should feel authentic and personal, not overly corporate or like an experienced senior developer's website.

==================================================

OVERALL VISUAL STYLE

==================================================

- Main theme: pink

- Use different shades of pink, from soft pastel pink to stronger accent pink

- Background should mostly be light, clean, and soft

- Use white and subtle pink-tinted surfaces for cards and containers

- Dark text for readability

- Rounded corners, soft shadows, glass-like elements where appropriate

- The design should feel playful and modern

- Avoid making it look too childish or overly cute

- Avoid a generic template appearance

Add subtle decorative elements such as:

- floating blobs or soft abstract shapes

- small stars, sparkles, dots, or playful graphic elements

- soft gradients

- subtle background movement

Use smooth animations and transitions throughout the experience.

==================================================

RESPONSIVE DESIGN

==================================================

The website must be fully responsive.

Design for:

- Desktop

- Tablet

- Mobile

Desktop should feel spacious and immersive.

Mobile should not simply shrink the desktop layout. Reorganize sections appropriately for smaller screens.

The navigation should transform into a mobile menu on smaller screens.

==================================================

NAVIGATION

==================================================

Create a clean navigation bar.

Desktop:

- Personal logo/name on the left

- Navigation links on the right:

  - Home

  - About

  - Skills

  - Projects

  - Experience

  - Education

  - Contact

The navbar should remain visible or become sticky while scrolling.

Use subtle transparency or a glass effect.

Mobile:

- Show the logo/name

- Show a hamburger menu

- The menu should open smoothly with animation

==================================================

GLOBAL PAGE MESSAGE / POP-UP

==================================================

One important feature of this portfolio is a small reusable pop-up or floating message that appears on every major section/page.

This message acts like a friendly guide and briefly explains what the visitor is looking at.

It should feel like part of the website's personality.

Examples:

HOME:

"Hi! Welcome to my little corner of the internet. Here's where you can explore my work, skills, and things I've been building."

ABOUT:

"A little bit about me, what I enjoy, and how I ended up loving technology."

SKILLS:

"Still growing! These are the tools and technologies I've explored and worked with so far."

PROJECTS:

"Here are some of the things I've built. Click around and try them out!"

EXPERIENCE:

"Some of the experiences that helped me learn and grow."

EDUCATION:

"A quick look at my academic journey so far."

CONTACT:

"Want to talk or work together? Here's where you can find me."

The message component should:

- have a playful speech bubble or floating card appearance

- animate when appearing

- be reusable across sections

- not block important content

- feel like a small guide accompanying the visitor

==================================================

HOME / HERO SECTION

==================================================

The home page should be the most visually interactive section.

Create a large hero area with:

- A personal introduction

- A heading such as:

  "Hi, I'm Xynex Kim"

  or a similar editable placeholder

- A short subtitle describing me as an IT student and aspiring developer

- A prominent interactive animated visual element

The animated element is very important.

Create a soft pink abstract object, blob, puff, bubble, or 3D-like shape that moves gently.

It does NOT need to follow the mouse.

However, when the user hovers over it, the animation should change into another state.

For example:

Default state:

- floating

- gently moving

- pulsing

- rotating slightly

Hover state:

- morph into a different shape

- bounce

- expand

- split into smaller elements

- change movement

- reveal another playful animation

The hero should encourage the visitor to interact with the visual element.

Add subtle text or an interaction hint if appropriate.

The hero should feel memorable and creative.

==================================================

ABOUT SECTION

==================================================

Create an About Me section that feels more creative than a standard "photo on the left, paragraph on the right" layout.

Explore a visually interesting layout.

Possible elements:

- personal introduction

- short story or journey into technology

- interests

- things I enjoy building

- personality or fun facts

Use cards, layered elements, playful positioning, or interactive details.

Leave the content easy to edit later.

Do not make this section look like a typical corporate resume.

==================================================

SKILLS SECTION

==================================================

Create a skills section that reflects someone who is still learning and building their skills.

Do not present the user as an expert in everything.

Use categories such as:

Frontend:

- HTML

- CSS

- JavaScript

- React

- Tailwind CSS

Backend:

- Python

- Django

Tools:

- Git

- GitHub

- VS Code

- Figma

The design can use:

- interactive skill cards

- floating icons

- draggable-looking elements

- playful tooltips

- hover animations

Include wording that communicates growth and learning.

Example:

"Still collecting tools for my developer toolbox."

Make the skill data easy to add or update later.

==================================================

FEATURED PROJECTS

==================================================

This should be one of the most visually interesting sections.

The portfolio should present projects through an animated flipping or rotating card/container.

The idea:

The visitor initially sees Project 1.

Then through interaction, scrolling, clicking arrows, or hovering, the project presentation flips or transitions to reveal the next project.

Example:

Project 1

↓

animated flip / rotation

↓

Project 2

↓

animated flip / rotation

↓

Project 3

Each project should contain:

- Project image or preview

- Project title

- Short description

- Technologies used

- Live Demo button

- GitHub / View Code button

The Live Demo button should clearly support linking to a separate deployed application where visitors can actually use the project.

Example projects:

- Pomodoro application

- To-Do or Task Management application

- Other future projects

The project cards should feel like an interactive presentation rather than a standard static grid.

==================================================

EXPERIENCE SECTION

==================================================

Create a separate container or section for experience.

Since the portfolio owner is an undergraduate student, experience may include:

- internship

- OJT

- school projects

- organizations

- other relevant experiences

Use a clean timeline or card-based layout.

Make it easy to add future experiences.

==================================================

EDUCATION SECTION

==================================================

Create a separate Education section.

Display:

- Degree

- School

- Year or expected graduation

- Relevant learning journey or achievements

This section should visually complement the Experience section but remain separate.

Consider placing Experience and Education near each other while giving them their own distinct containers.

==================================================

CONTACT / FOOTER

==================================================

Keep the contact section simple.

The footer can include:

- Name

- Email

- GitHub

- LinkedIn or other social links

- A small friendly closing message

Example:

"Thanks for stopping by ✦"

Add a subtle animated decorative element to finish the experience.

==================================================

ANIMATIONS AND INTERACTIONS

==================================================

Use smooth, intentional animations.

Include:

- hover effects

- smooth section transitions

- floating decorative elements

- animated entrance effects

- interactive hero object

- animated project flipping

- smooth mobile menu animation

- subtle button animations

- reusable animated page/section message

Avoid excessive animation that makes the website difficult to use.

Animations should enhance the experience, not distract from the content.

==================================================

TECHNICAL STRUCTURE

==================================================

Build the interface with a clean component-based structure.

Potential reusable components:

- Navbar

- PageMessage

- Hero

- About

- Skills

- ProjectShowcase

- ProjectCard

- Experience

- Education

- Contact

- Footer

Keep the design easy to expand later because new projects, skills, experience, and education entries will be added over time.

The initial focus is the frontend visual experience. The architecture should later be compatible with connecting a Django backend and API for dynamic content such as projects, skills, experience, education, and contact messages.

Do not build a generic developer portfolio template.

The final result should feel like:

- personal

- creative

- pink

- interactive

- modern

- polished

- responsive

- slightly experimental

- memorable

The website should communicate:

"I am still learning and building, but I enjoy creating things and experimenting with technology."
